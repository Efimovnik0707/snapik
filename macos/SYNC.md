# Синхронизация Windows → macOS

Источник истины: Windows-версия в `src/`. Mac-порт в `macos/` догоняет её порциями («синхронизациями»). Оба живут в одном git-репозитории (`Efimovnik0707/snapik`), поэтому «что изменилось на Windows» всегда выводится из `git diff`.

## Правила

1. Любое изменение Windows-версии коммитится в этот репозиторий (можно пачкой в конце сессии). Без коммита Mac-порт изменения не увидит.
2. Каждая синхронизация начинается тегом `mac-sync-base-N` на том коммите Windows-кода, который уже перенесён. Разница `git diff mac-sync-base-N HEAD -- src tests tasks` = что переносить.
3. Перенос: спека дельты (если изменение крупное) → исполнитель в `macos/Sources` → CI на macOS-раннере (сборка, 99+ тестов, smoke, DMG) → новый тег `mac-sync-base-N+1` и запись в журнал ниже.
4. Команда для запуска: «синхронизируй мак» (или «sync mac»). Агент сам находит тег, строит diff и делает перенос, в конце даёт ссылку на DMG.
5. Новые строки интерфейса на Windows добавляются в `UiLanguage.cs`; на Mac они попадают в `macos/Sources/SnapikCore/Settings/UiLanguage.swift` в том же порядке. Формат `session.json` и настроек менять только синхронно в обеих версиях.

Не перенесено синхронизацией №5 и ждёт следующей: **ротации `exports/revision-*` на Mac нет вовсе** (ни у пакета, ни у одиночной копии; Windows чистит их `TrimExports`, на Mac каждое «Копировать снимок» оставляет ещё один каталог до очистки ленты или до следующего старта, `SPEC-DELTA-5.md` §2.1); правило «одиночная вставка не чистит ленту» живёт в `SentCaptureRules.clearsTheStrip`, а `PreparedExport.clearsTheStrip` не реализован (§2.2); **многомониторный `workArea()`** перенесён частично (кламп уже стоящей ленты берёт экран её окна, всё остальное по-прежнему считает первый экран); **прокрутка внутри окна настроек** есть только у вкладки «Вид» — высота 620 лечит обрезку содержимого, а не монитор, который окно не вмещает; **редактор копирует снимок так, как его держит сессия**: незакрытые правки открытого окна в эту копию не попадают, а снимок, который ещё не лёг в сессию, не копируется вовсе; **платформенное Windows**: закреп на панели задач (`TaskbarPinLegacy`, `CarryOverLegacyPin`, шаг `PinCarryOver` мастера, три пары `UiLanguage` про панель задач, проба `VerifyALegacyPinIsCarriedOver`), `VerifyALayeredWindowMinimisesAsync` и лента как окно панели задач (на Mac приложение живёт агентом, `LSUIElement`), трасса `WM_DPICHANGED` с `DescribeGallery` и `DescribeChevronHit`, `OnGalleryScrolled`, `Controls/RoundedClip.cs` (на Mac это `layer.cornerRadius`), `FrameCopy.Detach`, `installer/Snapik.iss`. Отклонения владения этого раунда: `AppCoordinator+PasteIntent.swift` правила порция Stack, `Editor/ToolAppearanceStore.swift` писала волна 0 (`CONTRACTS.md`, дополнение sync 5). Интерактивная проверка на живом Mac по-прежнему не проведена, список в `README.md` «Что проверено и что нет». База следующей синхронизации — Windows HEAD на момент её начала.
