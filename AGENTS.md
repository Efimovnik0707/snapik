# SnapBrief: памятка для агентов

Приложение существует в двух версиях в одном репозитории `Efimovnik0707/snapbrief` (ветка `master`):

| Версия | Где | Кто ведёт | Статус |
|---|---|---|---|
| Windows (C#/WPF, .NET 10) | `src/`, `tests/`, `scripts/`, `tasks/` | Codex | источник истины, активно меняется |
| macOS (Swift/AppKit) | `macos/` | Claude, по команде «синхронизируй мак» | догоняет Windows порциями, см. `macos/SYNC.md` |

## Правила для работы над Windows-версией

1. **Коммитить в этот же репозиторий, в `master`.** Один коммит на законченную правку, сообщение по-английски с префиксом `windows:` (например `windows: palette popover keeps selection`). Не закоммиченные изменения для Mac-порта не существуют.
2. **Не трогать `macos/`** и `.github/workflows/macos-build.yml`. Там отдельный порт, он обновляется по diff Windows-кода.
3. **Новые строки интерфейса только через `src/SnapBrief.App/UiLanguage.cs`** (пара RU/EN в таблицу), не хардкодом в XAML. Mac переносит таблицу один в один.
4. **Формат данных не менять в одиночку:** `session.json`, `manifest.json`, `prompt.md`, файл настроек, формат ID горячей клавиши. Если изменение неизбежно, описать его в `tasks/verification.md` отдельным абзацем «Изменение формата», чтобы Mac поменял синхронно.
5. **Поведение фиксировать текстом.** Каждая функциональная правка получает одну-две строки в `tasks/verification.md` (что сделано, как проверено) или в отдельный план в `tasks/` (пример: `tasks/ui-editor-plan.md`). Mac-порт переносится по коду и по этим описаниям, комментарии в XAML/C# помогают.
6. **Тесты и smoke.** `scripts/build.ps1` гоняет 62+ тестов и `--smoke-test`. Новая логика получает тест или smoke-проверку; Mac переносит и их.
7. **Не менять то, что отклонено:** `MainWindow.xaml` исключён из сборки и не возвращается (`README.md`, `tasks/verification.md`).

## Что уже есть

- Полный сценарий: горячая клавиша → выделение → разметка (рамка, стрелка, перо, маркер, текст, скрытие, размытие, обрезка, ручки, undo/redo) → комментарии → лента снимков → пакет в буфере → детект вставки и ротация сессии → сохранение в файл → настройки, автозапуск, single instance. Подробно: `README.md`, `PRODUCT.md`, `tasks/prd-snapbrief.md`, `tasks/verification.md`.
- Панель цвета и толщины (палитра, HEX, ползунок), меню «…», подсказки с клавишами: `tasks/ui-editor-plan.md`.
- Mac-версия повторяет всё это на состояние коммита `mac-sync-base-1`, собирается и тестируется в GitHub Actions, DMG в Releases.

## Синхронизация с Mac

Делает Claude: `git diff mac-sync-base-N HEAD -- src tests tasks` → перенос в `macos/` → CI → новый тег. Журнал и правила: `macos/SYNC.md`. От Windows-агента нужны только закоммиченные изменения и заметки по пункту 5.
