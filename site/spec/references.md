## Скелет (общий для трёх вариантов)

1. Nav: лого, How it works, Features, Pricing, FAQ, переключатель RU/EN, кнопка Download for Windows наружу (все 8 сайтов).
2. Hero: H1 в одну мысль, sub с категорией и платформой, primary CTA = скачать, secondary = «Как это работает», микро-строка снятия риска (CleanShot, Casso). Демо продукта живой DOM-анимацией (Casso), но узнаваемой как реальный интерфейс приложения.
3. Works with: Claude Code, Codex, «любой композер, принимающий вставку изображений» (Casso), без логотипов чужих брендов.
4. Флагманский блок: один Ctrl+V = несколько PNG + структурированный текст (CleanShot «Always one drag away»).
5. How it works: 3 шага (Casso, Screen Studio).
6. Features 6 блоков, заголовок = результат (CleanShot), у каждого мини-демо (Casso), а не иконка.
7. Proof без отзывов: «что реально получает агент» (формат PromptGenerator) + «до/после» (Shottr: доверие через конкретику).
8. «Сделано для Windows 11» (CleanShot «Built for everyday Mac workflows») — отстройка: Windows доступен сейчас.
9. Pricing одной карточкой, one-time (CleanShot, Casso, Xnapper). Цена и условия — SAMPLE, помечены.
10. FAQ из прямых возражений (Warp, Casso).
11. Финальный CTA одной фразой (Raycast) + повтор кнопки.
12. Footer компактный.

## Анимации (источники)

- Hero-reveal: opacity 0→1, y 22→0, 0.8s, power3.out, stagger 0.1 (Casso, GSAP). У нас — WAAPI/CSS без библиотек.
- Scroll-reveal: y 28→0, 0.75s, старт «top 88%», один раз (Casso). Контент видим по умолчанию, reveal — enhancement; reduced-motion выключает.
- Hero-демо: курсор → рамка → бейдж-номер → печать заметки → затемнение → промпт уезжает в композер (Casso). Наша версия — по `product-mock.md`, с реальным fold в стопку.
- Мини-демо в фичах: бесконечный цикл, пауза вне вьюпорта (Casso, IntersectionObserver).
- Аккордеон FAQ: 0.22s вниз / 0.18s вверх (Casso).
- Hover: только opacity / фон / бордер, 150ms (Casso). Без 3D-тилтов.
- Grain-плёнка и edge glow — вариант C, донор Linear.
- Sticky-scroll фич — вариант B, донор Screen Studio.

## Три визуальных направления

A. **Светлый, утилитарный (канон категории на светлом).** Белый `#FFFFFF` / `#F5F6F8`, чернила `#172033`, акцент `#315CF5` (это реальная светлая тема приложения). Радиусы 8–12 (Shottr), крупный voздух, синие кнопки. Шрифты: Wix Madefor Display (заголовки) + Golos Text (текст), JetBrains Mono для клавиш. Донор структуры: CleanShot/Shottr.

B. **Тёмный, «как само приложение».** Фон `#0B0E13` → поверхности `#171A20` / `#242A33` (реальные цвета стопки), бордеры `#39424E`, акцент `#2F8CFF`. Радиусы 12–16, стекло только на nav. Sticky-scroll в блоке фич (Screen Studio), панель-мокап с тем же charcoal. Шрифты: Geologica (заголовки) + Onest (текст), JetBrains Mono. Донор: CleanShot dark / Casso / Screen Studio.

C. **Редакционный разворот «changelog» с ультрамарином.** Направление из броска impeccable (seed 98407afb, кандидат 5 собственного списка). Cool off-white `#F2F3F5` + чернила `#0B0F1A` + committed-ультрамарин `#2038E6`, занимающий целые поля (hero-поле, pricing). Линейки-хайрлайны, нумерованные записи как в release notes, строчный регистр заголовков (Warp), grain (Linear) на ультрамариновых полях. Донорские дисциплины из броска: Miura-fold — «одно движение разворачивает пакет» как сигнатурная анимация (стопка → 3 снимка + текст); осциллограф — всё выровнено по измеренной сетке. Шрифты: Unbounded (заголовки) + Literata (текст), JetBrains Mono для номеров записей и клавиш.
