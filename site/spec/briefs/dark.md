# SnapBrief landing — variant B (dark)

## Mode

Persuade. Desktop web, responsive to 390px. Bilingual RU/EN via in-page toggle.

## Direction contract

THESIS: The page is made of the same material as the app: charcoal panels, blue outlines, circular labels. Product and site share one skin, so the mock reads as continuous with the surface. Refuses the neon-glow-on-black rut and the bento of eighteen tiles.

OWN-WORLD: Ground `#0B0E13`, panels `#171A20`, cards `#242A33`, hover `#303845`, borders `#39424E`/`#46515F`, text `#EEF2F8`, secondary `#BFC8D6`, accent `#2F8CFF`, focus `#7AB8FF`. Radii 12–16, 1px borders carry depth, shadows `0 5px 24px rgba(0,0,0,.42)`. Backdrop blur only on the sticky nav. Display Geologica 600, body Onest, keys JetBrains Mono. Sticky-scroll feature storytelling (Screen Studio): the mock stays pinned while six feature texts scroll past and the mock state changes per feature.

STORY: A developer recognises the app's own panel language in the page, watches the loop, then scrolls the pinned mock through each feature state, sees the exact prompt text, and downloads.

FIRST VIEWPORT: Nav 64px. Centered H1 (clamp 44–72px) and sub, two CTAs, risk line. Below, full-width product mock 1100px wide on a subtle radial spotlight, running the loop; the edge stack sits at the mock's right edge. "Pastes into" row beneath.

FORM: Category canon, dark rendition, alongside cleanshot.com dark, usecasso.app, screen.studio. Seed 98407afb applies to variant C. Signature motion: fold into stack + sticky feature states.
