# SnapBrief — продуктовый мокап для лендинга (единый для всех трёх вариантов)

Источник правды: `src/SnapBrief.App/Themes/SnapBriefTheme.xaml`, `OverlayEditorWindow.xaml`, `EdgeStackWindow.xaml`, `PromptGenerator.cs`. Мокап рисуется HTML/CSS, не картинкой. Он должен быть узнаваем как приложение, а не как абстракция.

## Что показывает приложение (реальное поведение)

1. **Захват.** Глобальная клавиша → экран замирает и затемняется (backdrop `rgba(10,13,18,.55)`), пользователь тянет прямоугольник. Подсказка внизу: «Выделите область · Esc отменяет» / "Select a region · Esc cancels".
2. **Разметка поверх экрана.** Выделенная область остаётся яркой, вокруг тёмный backdrop. Плавающая панель инструментов под областью: Выбор, Область, Стрелка, Перо, Маркер, Текст, Скрыть, Размыть, Обрезать, цвет, толщина, Комментарий, Undo, Redo, Сохранить (Ctrl+S). Панель: фон `#171A20` при 95% (`#F2171A20`), радиус 12–16, бордер `#3A424E`, иконки `#9AA7B8`, активный инструмент `#2F8CFF`.
3. **Рамка‑аннотация.** Синяя рамка `#2F8CFF` 2px, радиус 4, круглая метка 20px `#2F8CFF` с белой цифрой (1, 2, 3). Сразу после рисования рамки рядом открывается компактное поле комментария: чип `#171A20`/95%, радиус 9–10, бордер `#46515F`, текст `#EEF2F8`, крестик удаляет заметку.
4. **Fold в стопку.** Клик по затемнению или Ctrl+C: редактор сворачивается (160–200 мс) в миниатюру узкой стопки у правого края экрана. Стопка: shell `#171A20`/95%, радиус 16, тень `0 5px 24px rgba(0,0,0,.42)`, заголовок «SnapBrief» + счётчик в пилюле `#2B3440`, карточки‑миниатюры 82px высотой `#242A33` бордер `#39424E` радиус 10 с круглой меткой `#2F8CFF` (A, B, C). Синяя кнопка «+ Снимок» / "+ Capture" `#2F8CFF`. На hover у миниатюры крестик, после удаления inline «Вернуть»/"Restore" `#7AB8FF`.
5. **Вставка.** В Claude Code / Codex пользователь жмёт Ctrl+V: приходят 3 отдельных PNG + текст. Текст (формат PromptGenerator):

```
Снимок A — Настройки.
Комментарий к снимку:
Экран после сохранения профиля.
A1: Кнопка «Сохранить» не меняет состояние после клика.
A2: Тост перекрывает поле email.

Снимок B — Список заказов.
B1: Сортировка по дате сбрасывается при обновлении.
```

EN‑версия текста для англоязычного лендинга (это демонстрация, помечать не нужно, формат тот же): `Capture A — Settings.` / `Capture note:` / `A1: …`.

## Палитра приложения (для мокапа, одинакова во всех вариантах)

- charcoal shell `#171A20` (95%), карточка `#242A33`, hover `#303845`, бордеры `#39424E` `#3A424E` `#46515F`, пилюля `#2B3440`
- акцент overlay `#2F8CFF`, фокус `#7AB8FF`, акцент светлой темы `#315CF5`
- текст на charcoal `#EEF2F8`, вторичный `#BFC8D6`, иконки `#9AA7B8`
- danger `#FF9B95`
- шрифт внутри мокапа: `"Segoe UI Variable Text","Segoe UI",system-ui` 12–13px

## Демонстрационный контент внутри мокапа (синтетический, но правдоподобный)

Замороженный «рабочий стол»: окно веб‑приложения (панель настроек или список заказов) с реальным текстом на языке страницы, не серые плашки. Три захвата: A «Настройки» (2 рамки), B «Список заказов» (1 рамка), C «Терминал» (1 рамка, blur‑область поверх токена). Комментарии короткие, 4–9 слов.

Заметки на RU/EN берутся из `site/copy.json` → `demo`.

## Иконки

Только инлайн SVG (stroke 1.5–1.75, 16/20px сетка, одна манера). Никаких эмодзи. Для инструментов: cursor, square, arrow-up-right, pen, highlighter, type, eye-off, droplets (blur), crop, undo, redo, download.

## Анимация hero‑демо (одна оркестрованная сцена, цикл ~9 с, пауза 1,5 с между циклами)

0.0s экран замирает: backdrop появляется (opacity 0→.55, 240ms)
0.4s рамка выделения тянется из угла (scaleX/scaleY 0→1, 420ms, ease-out expo)
1.0s панель инструментов всплывает под областью (translateY 8→0 + opacity, 200ms)
1.4s рисуется рамка‑аннотация 1 (240ms), появляется метка «1» (scale .6→1, 180ms)
1.8s чип комментария появляется рядом, текст печатается посимвольно (~30ms/символ)
3.4s рисуется рамка 2 + метка «2», чип с текстом
4.8s fold: область сворачивается в миниатюру стопки у правого края (transform + opacity, 180ms), счётчик стопки 0→1
5.4s быстрый повтор для снимка B (сжатая версия, 1.2s) → счётчик 2
6.8s курсор идёт в композер агента, `Ctrl+V` подсвечивается как клавиши, в композере появляются 2 вложения‑чипа и текст промпта (печать построчно)
8.6s пауза, затем цикл. `prefers-reduced-motion`: показать финальный кадр статично (стопка + композер с пакетом).

Реализация: CSS keyframes + небольшой JS‑таймлайн (setTimeout цепочка или Web Animations API), без библиотек. Контент по умолчанию видим (финальный кадр), анимация — enhancement.
