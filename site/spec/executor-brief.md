## Результат

Один файл `site/src/<variant>.html` (variant = `light` | `dark` | `editorial`). Автономный: весь CSS и JS внутри, без библиотек и внешних скриптов. Разрешены только шрифты Google Fonts через `<link rel="preconnect">` + `<link rel="stylesheet">` (с fallback‑стеком). Никаких картинок‑файлов: логотип, иконки, мокап — инлайн SVG и HTML/CSS. Целевой размер файла до 250 КБ.

Сборка: `node site/build.mjs` подставляет словарь вместо маркера и пишет `site/dist/<variant>.html`. В исходнике маркер обязателен ровно один раз:

```js
const COPY = /*__COPY__*/;
```

После сборки открывать для проверки нужно `site/dist/<variant>.html`. Ты не имеешь браузера: проверь синтаксис JS, вырезав содержимое `<script>` в временный файл и запустив `node --check`; проверь, что `node site/build.mjs` проходит; проверь `grep -c` на отсутствие эмодзи и запрещённых паттернов (см. ниже). Визуальную проверку сделает оркестратор.

## Локализация

- Язык определяется так: `?lang=ru|en` в URL → `localStorage.snapbrief_lang` → `navigator.language` начинается с `ru` → `ru`, иначе `en`.
- Переключатель в nav (кнопка с текстом `COPY[lang].nav.lang`) меняет язык без перезагрузки: перерисовывает все тексты, ставит `document.documentElement.lang`, `<title>`, `<meta name="description">`, сохраняет выбор в localStorage и в URL через `history.replaceState`.
- Статические тексты через `data-i18n="hero.h1"` (путь в словаре), списки (features, steps, faq, compare, footer, worksWith, risk, points) рендерятся JS из массивов. Всё, что видит пользователь, берётся из `COPY`, включая тексты внутри мокапа (`demo`).
- Кириллица — первый тест‑кейс: заголовки на русском длиннее, проверяй переносы по длине строк (`hero.h1` RU и EN должны влезать в 2–3 строки на десктопе, без переполнения на 390px).

## Продуктовый мокап и анимация

- Реализовать по `product-mock.md`: замороженный экран с правдоподобным окном приложения (текст из `demo.fakeApp`), затемнение, рамка выделения, плавающая панель инструментов с SVG‑иконками, синие рамки‑аннотации `#2F8CFF` с круглыми номерами, чипы заметок из `demo.captures[*].notes`, стопка у правого края (`#171A20`, миниатюры, метки A/B/C, кнопка `demo.stackButton`), композер агента (`demo.composer`), клавиши `<kbd>` из `demo.kbd`.
- Таймлайн цикла реализовать на Web Animations API или CSS‑keyframes + один управляющий JS (`setTimeout`‑цепочка с очисткой). Пауза цикла, когда мокап вне вьюпорта (IntersectionObserver). `prefers-reduced-motion: reduce` → статичный финальный кадр без цикла.
- Контент страницы видим по умолчанию. Scroll‑reveal (opacity 0→1, y 28→0, 750ms, exponential ease‑out, старт при `top 88%`, один раз) добавляется классом через IntersectionObserver и только если reduced‑motion выключен. Не делать одинаковый вход на каждой секции: hero — свой stagger, мокап — свой сценарий, фичи — своё появление.
- Hover: opacity/фон/бордер, 150ms. Никаких 3D‑tilt и магнитных кнопок.

## Планка качества (из craft-floor, коротко)

- Контраст текста ≥ 4.5:1, крупного ≥ 3:1. Вторичный текст на цветных полях тонирован от фона, не серый.
- Тени с offset и blur. Никаких цветных halo без смещения.
- Тип: измерение основного текста 65–75ch, display ≤ 6rem, tracking не ниже −0.04em, `text-wrap: balance` на заголовках, `text-wrap: pretty` на абзацах.
- Браузерные поверхности оформлены: `::selection`, `caret-color`, `scrollbar` (`scrollbar-color`), `:focus-visible` кольцо в цвете акцента, `text-underline-offset`, `font-variant-numeric: tabular-nums` где цифры.
- Состояния: hover, focus-visible, active у всех кнопок и ссылок; `<details>` открыт/закрыт.
- Иконки только инлайн SVG одной манеры (stroke 1.5–1.75, сетка 20/24). Эмодзи запрещены везде.
- Запрещено: кикеры/eyebrow‑надписи над заголовками (совсем), градиентный текст, стекло как декор (blur только на sticky‑nav, если бриф разрешает), `border-left` цветной толще 1px, жёсткие тени `4px 4px 0`, одинаковые карточки «иконка+заголовок+текст» как структура фич, номера секций 01/02 кроме `how` и (в editorial) записей changelog, где последовательность и есть смысл.
- Адаптив: 1440, 1280, 1024, 768, 390. На 390 nav сворачивается в компактный ряд (лого, язык, кнопка), мокап масштабируется (`transform: scale` от контейнера через `--mock-scale` или fluid‑единицы), таблица before/after становится одной колонкой.
- Семантика: один `<h1>`, секции с `<h2>`, `<nav>`, `<main>`, `<footer>`, `aria-label` на кнопке языка, `aria-hidden` на декоративных SVG.
- Логомарк: SVG по мотивам иконки приложения — синий (`#2563EB`→ для light/dark, ультрамарин для editorial) скруглённый квадрат, внутри белая рамка экрана с тонким контуром и маленькая белая карточка заметки с тремя линиями в правом нижнем углу. Favicon — этот же SVG как data‑URI в `<link rel="icon">`.
