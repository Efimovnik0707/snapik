# План доводки панели разметки SnapBrief

Цель: пользователь выбирает инструмент и параметры напрямую, видит текущее состояние и может исправить действие без перебора скрытых значений. Сохраняется компактный тёмный интерфейс поверх снимка.

## Реализовано

- Цвет и толщина вынесены в видимую кнопку основной панели с текущим цветом и числом пикселей.
- Палитра: 12 образцов, выделение выбранного цвета, ввод HEX с проверкой. Окно не закрывается при выборе.
- Толщина: ползунок 1–16 px, движение в обе стороны и пример линии. Для текста толщина недоступна; для блюра, обрезки и сплошного скрытия параметры цвета недоступны.
- Выбранный объект изменяется сразу; правки его цвета и толщины за одно открытие палитры отменяются одним Undo. Без выбранного объекта параметры применяются к следующим отметкам.
- В меню «…» оставлены перо, маркер и сплошное скрытие. Удалён разделитель, выбранный пункт отмечен, кнопка меню отражает активность дополнительного инструмента.
- Подсказки инструментов основной панели содержат V/R/A/B/C; текст T и комментарий N; дополнительные P/H/X. Undo/Redo показывают Ctrl+Z/Ctrl+Y и недоступны без истории. Save показывает Ctrl+S.

## Проверки перед визуальным принятием

- Автоматически: смена цвета и толщины выбранного объекта, возврат толщины с 14 до 2, восстановление исходного вида одним Undo; ввод текста; экспорт; размещение панели вне узкого выделения.
- Вручную: открытие палитры, выбор нескольких образцов без закрытия, движение ползунка мышью, Enter в HEX, закрытие крестиком/Esc/снаружи без завершения снимка; рисование каждым инструментом; узкое выделение у всех краёв при рабочем DPI.
- Проверить внешний вид popup, выбранного цвета, фокуса и disabled. Отсутствие ошибок сборки не заменяет эту проверку.

Живая визуальная приёмка остаётся открытой: средство Computer Use не перечисляет окно SnapBrief среди доступных окон. Не отмечать интерфейс полностью принятым до наблюдения этих сценариев.

## Комментарии, просмотр и стопка — ревизия 9 сентября

Исходные требования полностью сохранены в `editor-revision-input.md`.

1. Текст T — основная кнопка; пишет непосредственно в изображение. Комментарий N — отдельная заметка с привязкой к снимку или выбранной отметке. После N один клик по изображению задаёт позицию одной новой заметки; режим автоматически возвращается к выбору. Для следующей заметки снова нажимается N или кнопка комментария.
2. Рамка автоматически открывает необязательный первый комментарий. Плавающей дублирующей кнопки нет; дополнительные заметки доступны из основной панели. У заметки нет прямоугольника выделения и угловых ручек. Комментарии не ограничены одним полем; номера формируются из непустых заметок и совпадают в редакторе, просмотре и экспортируемом тексте. После Z снимки получают AA, AB и далее.
3. Enter завершает ввод и сворачивает заметку; Shift+Enter добавляет строку. Наведение раскрывает, клик закрепляет ввод, уход фокуса сворачивает. Возврат к снимку восстанавливает заметки. Текст изображения открывается для правки двойным кликом.
4. Claude определяется по активному процессу при физическом Ctrl+V. Для принадлежащего SnapBrief пакета последовательно вставляются отдельные изображения через зарегистрированный формат PNG, затем текст. Перед действиями проверяются окно, фокус и версия буфера; Enter не отправляется. Реальный приём Claude остаётся отдельной проверкой.
5. У стрелки выбор с визуальными образцами: прямая, изогнутая, толстая, широкий наконечник. Рендерер общий для редактора и экспорта.
6. Края рамки, blur и сплошного скрытия доступны для переноса без переключения инструмента; углы меняют размер. После наведения активный инструмент остаётся прежним.
7. «+ Снимок» удалён из панели разметки. Следующий захват вызывается привычной горячей клавишей.
8. Снимок открывается в отдельном перемещаемом и изменяемом по размеру просмотре на мониторе стопки. Доступны масштаб, вписать, 100%, разворот окна и возврат в разметку. Клик снаружи закрывает просмотр.
9. Автосохранение готового захвата включается в настройках и использует выбранные папку и формат. При выключении отдельный пользовательский файл создаётся по Save; внутренние черновики сессии продолжают обеспечивать восстановление.
10. Просмотр показывает комментарии, позволяет добавлять, редактировать и удалять их; изменения сохраняются и обновляют принадлежащий приложению буфер. Удаление не оставляет устаревшие номера.
11. Стопка ограничена по высоте, раскрывает карточку при наведении и прокручивается. Открытая карточка отмечена до закрытия просмотра.
12. Встроенные записи затвора Canon и колёсика Instax (CC0) отключаются общей настройкой; щелчки колёсика ограничены интервалом 170 мс и не прерывают затвор в первые 400 мс. Ошибка аудиоустройства не прерывает захват.

Приёмка: полный build со smoke; затем живые сценарии мышью, 300 снимков в стопке, два монитора со смешанным DPI, фактическая вставка в Claude и Codex. Автоматические проверки не подтверждают визуальное качество или приём вложений внешним приложением.
