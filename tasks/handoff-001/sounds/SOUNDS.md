| Файл | Куда в приложении |

| click-tiny-005s.mp3 | наведение на кадр в панели (на 25 % громкости), клик по инструменту |
| click-app-interface-008s.mp3 | чекбокс, пункт меню |
| click-soft-plastic-013s.mp3 | альтернатива для клика по инструменту |
| ui-tap-089s.mp3 | появилась пилюля комментария |
| ui-pop-136s.mp3 | снимок сложился в панель |
| shutter-1-039s.mp3 / shutter-2-050s.mp3 / shutter-3-068s.mp3 | момент захвата (рекомендуется shutter-2) |
| camera-click-050s.mp3 / camera-capture-062s.mp3 | альтернативы для захвата |
| notify-soft-012.mp3 / notify-soft-040.mp3 / notify-soft-062.mp3 / notify-soft-dragon.mp3 | «скопировано в буфер», «сохранено» (рекомендуется 040) |
