## A. Первый запуск и онбординг — приоритет 1

### A1. Нет онбординга
После установки только ярлык на рабочем столе. Непонятно, как вызвать приложение, где оно живёт, какими клавишами пользоваться.

Ожидание, как у Handy: при первом запуске мастер из 3–4 шагов.
1. Язык: Русский / English.
2. Горячая клавиша скриншота: поле, куда сразу нажимаешь своё сочетание.
3. Галочки «Закрепить на панели задач», «Запускать с Windows».
4. Короткая анимированная подсказка: нажми клавишу → выдели область → добавь комментарии → Ctrl+V в чат.

Повторно мастер доступен из меню трея: «Как пользоваться».

Код: `src/SnapBrief.App/App.xaml.cs` (first-run логики нет), язык жёстко `ru` в `UiLanguage.cs:12` и `HotkeySettingsWindow.xaml.cs:27`.

### A2. Закрепление на панели задач
Установщик `installer/SnapBrief.iss` делает только ярлык; окно стопки `ShowInTaskbar="False"`. В мастере предложить закрепление. Программный pin ограничен Windows, поэтому допустимо показать подсказку «перетащи ярлык на панель задач» с картинкой.

## B. Панель со снимками (EdgeStackWindow)

### B1. Панель теряется за окнами
`EdgeStackWindow.xaml:7` `Topmost="False"`, настройки нет. Когда открыто много окон, приходится всё сворачивать, чтобы найти панель.

Требование: по умолчанию поверх всех окон. Переключатель «Поверх других окон» в меню «•••». Фокус по-прежнему не красть (`ShowActivated="False"`).

### B2. Снимки пропадают
Сделала два снимка, один удалила, сделала третий — второй исчез.

Причина в коде: `EdgeStackWindow.xaml.cs:801 StartNewSessionAsync` очищает панель при вставке Ctrl+V / Alt+V в другое приложение (`:270`), при следующем захвате, если буфер обмена перезаписан чужим копированием (`:461`, `:477`), и вручную «Новая сессия». Файлы на диске остаются (`%LOCALAPPDATA%\SnapBrief\sessions`), но пользователь этого не видит, для него это потеря.

Требование, без усложнения:
- Панель живёт, пока пользователь сам её не очистил.
- Убрать автосброс по чужому копированию в буфер.
- После вставки снимки не стирать, а помечать «отправлено» (лёгкое затемнение или галочка).
- Кнопка «Очистить» в шапке панели.
- Одна необязательная настройка: «Очищать панель после вставки», по умолчанию выключена.

### B3. Кнопка «Вернуть» непонятна
`EdgeStackWindow.xaml:186`. Появляется после удаления снимка и не прячется при новой сессии (`:815` чистит `_removed`, кнопку не скрывает).

Требование: заменить на тост «Снимок удалён · Отменить» на 5 секунд, как в Gmail. Постоянную кнопку убрать.

### B4. Иконка «Новый снимок» обрезана справа
`EdgeStackWindow.xaml:166`: `Path Width="15"`, геометрия до x=16. Поставить Width=17 или обернуть в Viewbox.

### B5. «Импортировать файл…» не работает
`EdgeStackWindow.xaml.cs:681 ImportFileAsync`. Вероятные причины: диалог открывается под окнами (Topmost=False, ShowActivated=False), ошибки уходят в строку статуса и не видны, фильтр только png/jpg, ожидание `_pasteIntentTransition` (`:682`) может блокировать.

Требование: диалог поверх, ошибки показывать явно, добавить webp/bmp/gif, проверить блокировку.

### B6. Размер панели
Ширина 208 фиксирована. Требование: тянуть за левый край (курсор ↔), диапазон 180–360, запоминать.

### B7. Звук при наведении на кадры
`EdgeStackWindow.Preview.cs:58` играет `camera-dial-click.wav` через `SoundPlayer`, громкость не регулируется.

Требование: очень тихий мягкий тик, еле слышный, но приятный при проведении мышкой по кадрам. Громкость 20–30 % через `MediaPlayer.Volume`. Пример в папке `sounds/`: `click-tiny-005s.mp3`. Троттлинг оставить.

### B8. Название панели
Сейчас в тексте «стопка», «превью». Нужно одно слово в интерфейсе и доках. Предложение: «Лента снимков».

## C. Разметка (OverlayEditorWindow, AnnotationCanvas)

### C1. Комментарии неудобные и не двигаются
Пилюли комментариев (`OverlayEditorWindow.xaml.cs:463 AddChip`) только сворачиваются, перетаскивать нельзя. Пин комментария двигается только в режиме Select (`AnnotationCanvas.cs:193`). «Лапка» для перемещения есть только у Rectangle / Blur / Conceal (`AnnotationCanvas.cs:417–427 FindMoveEdge`).

Требование:
- Единый хват (иконка ✥, курсор SizeAll при наведении на край) у всех объектов: рамка, стрелка, текст, размытие, пилюля комментария, стикер.
- Пилюлю можно оттащить от рамки, связь показывается тонкой линией.
- Комментарий к объекту пишется в один клик по объекту, без поиска кнопки на панели.

### C2. Фигуры и заливка
Есть только острый прямоугольник (`AnnotationItem.cs:5–15 AnnotationKind`, `AnnotationCanvas.cs:360`). Заливки нет.

Требование:
- Кнопка «Фигура» с выпадающим списком: прямоугольник, скруглённый прямоугольник, круг/овал. Стандартный набор, без лишнего.
- Заливка выбранным цветом: переключатель «Контур / Заливка / Полупрозрачная заливка» в поповере «Цвет и толщина».
- В модель `AnnotationItem.cs` добавить `Shape` и `Fill`, экспорт в `WpfExportImageRenderer.cs`.

### C3. Стрелки в одной кнопке
Сейчас стиль стрелки в отдельной кнопке-уголке (`OverlayEditorWindow.xaml:100`, `OverlayEditorWindow.Arrows.cs:14`: прямая, изогнутая, толстая, широкая).

Требование: выпадающий список открывается из самой кнопки «Стрелка» (клик — инструмент, уголок или удержание — меню). В меню 3–4 стандартные формы наконечника и слайдер толщины. Отдельную кнопку убрать.

### C4. Показывать горячие клавиши
Клавиши уже есть (`OverlayEditorWindow.xaml.cs:837–874`: V выбор, R рамка, A стрелка, B размытие, C обрезка, P перо, H маркер, T текст, N комментарий, X скрыть; Ctrl+S/Z/Y/C, Esc), но их не видно.

Требование: буква в тултипе и маленькая подпись под иконкой при наведении на панель. Шпаргалка «?» в углу.

### C5. Стикеры и эмодзи
Инструмента нет. Требование: кнопка «Стикер» с сеткой из 12–16 стандартных эмодзи (✅ ❌ ⚠️ 👉 ⭐ ❤️ 🔥 💡 ❓ цифры). Вставляется как масштабируемый объект с той же лапкой.

### C6. «Сохранить как» с выбором формата
Ctrl+S (`OverlayEditorWindow.Save.cs`) должен предлагать PNG / JPEG / WebP в диалоге для этого конкретного снимка, независимо от глобальной настройки формата.

### D2. Поле горячих клавиш не выглядит кликабельным
Нашла случайно. Требование: поле выглядит как кнопка с капсулами клавиш (`Ctrl` `Shift` `S`) и подписью «Нажми, чтобы изменить», иконка клавиатуры. Основная настройка в онбординге (A1).

### D3. Язык
Спрашивать при первом запуске (A1). Переключатель в настройках остаётся.

### D4. Качество JPEG
Дефолт 90 (`HotkeySettingsWindow.xaml.cs:25`), непонятно, что за число. Требование: показывать только когда выбран JPEG. Подпись «Качество JPEG: 90 % (меньше — легче файл)». Дефолт 92.

### D5. Нет крестика
Окно закрывается только «Отмена» / «Сохранить». Добавить крестик в правом верхнем углу, действие = Отмена.

### D6. «Сохранить» бледнеет при наведении
Баг в `Themes/SnapBriefTheme.xaml:53`: триггер BaseButton (`TargetName=Chrome` → HoverBrush) перебивает `:69` PrimaryButton AccentHover. Исправить отдельным триггером для PrimaryButton, при наведении кнопка должна темнеть, а не бледнеть.

### D7. Внешний вид приложения
Настроек вида нет. Требование: вкладка «Вид»: Тёмная (текущая), Светлая, плюс 3–4 акцентных цвета или мягких градиента для панели снимков и тулбара. Спокойные, в стиле Apple. Акцентный цвет вынести в один ресурс (`#2F8CFF` сейчас разбросан по XAML). Конкретные палитры Катя подберёт и пришлёт отдельно.

## E. Сохранение пакета

### E1. Папка создаётся без спроса
`EdgeStackWindow.xaml.cs:725–733 SavePackageAsAsync` всегда создаёт подпапку `SnapBrief-yyyyMMdd-HHmmss`. Пример: `SnapBrief-20260912-171827` с файлами `A_e16481c2….png`, `B_63b4d7ae….png`, `manifest.json`, `prompt.md`.

Требование:
- Диалог с полем «Имя папки» (предзаполнено) и галочкой «Создать подпапку». По умолчанию включена. Если выключена, файлы кладутся прямо в выбранную папку с префиксом даты. Так можно копить скриншоты в одну папку.
- Имена файлов короче: `01-A.png` вместо `A_<guid>.png`, guid оставить в manifest.

### E2. Что такое prompt.md и manifest.json
Пользователю непонятно, зачем они. Либо одна строка пояснения в диалоге сохранения, либо `manifest.json` не показывать.
