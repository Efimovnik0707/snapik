# ТЗ №3, дорожка E (редактор разметки): что сделано и как проверено

Пункты 1, 2, 5, 6 ТЗ Никиты (`tasks/handoff-003/TZ-003-nikita-v130.md`), план `tasks/tz-003-details/editor.md`. Пункты 3 и 4 вела другая дорожка. Каждый пункт это один коммит, перед каждым коммитом прогонялся `scripts/build.ps1` (тесты, publish, `--smoke-test`).

## П.1. Клик вне снимка снова завершает разметку

Сделано. Ветка «клик мимо снимка» в `OnWindowMouseUp` снова зовёт `Complete(false)`, как было до ТЗ №2. Правило внутри снимка не тронуто: клик по пустому месту обрабатывает холст (`AnnotationCanvas.BeginGesture` зовёт `Select(null)` и заводит черновик, который умирает без движения руки), до оконного обработчика он не доходит.

Решение классифицируется одним методом `TakeOutsideClick(source, point)` с тремя исходами: `Ignore` (клик по снимку или не по фону), `Spent` (этим же нажатием закрыли пилюлю заметки, второе действие тем же кликом не делается), `Finish` (завершить разметку). Флаг «клик потрачен» ставит `PressBesideEditors`, который зовётся из `OnWindowMouseDown`, и снимает сам `TakeOutsideClick`, поэтому следующий клик снова завершает съёмку. Открытый поповер закрывается сам (`StaysOpen="False"`), окно этого клика не видит, значит первый клик закрывает поповер, второй завершает съёмку.

Как проверено: smoke-проба `RunOutsideClickProbe` (вызов в `SmokeTestRunner`, рядом с пробами редактора). Проверяет четыре случая: клик по фону вне снимка даёт `Finish`, клик в пределах снимка даёт `Ignore`, клик не по `DesktopImage` даёт `Ignore`, клик при открытой пилюле заметки закрывает пилюлю и даёт `Spent`, а следующий снова `Finish`. Правило «клик внутри снимка снимает выделение и ничего не рисует» уже покрыто `AnnotationCanvas.VerifyGestureRules`, дублировать не стал.

Живьём не проверено: настоящий клик мышью по затемнению вокруг снимка (smoke гоняется без окна на экране, `Complete` в пробе не вызывается, потому что `DialogResult` можно ставить только окну, показанному через `ShowDialog`). Проверяется классификация клика, то есть вся ветка решения, кроме самого вызова `Complete`, который в этой ветке не менялся с 1.2.0.
