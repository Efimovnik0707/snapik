# SnapBrief — контекст интерфейса

Пользователь: Никита, Windows, Claude Code и Codex в терминале и desktop-приложениях. Задача — быстро собрать несколько скриншотов с разметкой и связанными заметками и вставить готовое задание без ручной нумерации.

Принятый пользователем дизайн: разметка непосредственно поверх замороженного экрана, компактные комментарии рядом с областями и стопка законченных снимков у края рабочего стола. Визуальные ориентиры — присланный Casso и Lightshot. Большое белое окно с правой панелью и нижней лентой отклонено как основной сценарий.

Действующий контракт: `.impeccable/surfaces/src-snapbrief-app-overlayeditorwindow-xaml.md`. Референс пользователя: `.impeccable/references/user-casso.png`. Сверяться с ними перед изменением интерфейса.

Обязательные свойства: быстрое появление, редактирование заметки сразу после рисования, сохранение связей при изменении порядка, возврат к работе через маленькую стопку, читаемые подписи и клавиатурный фокус. Снимки и текст остаются локальными. Ошибка вставки не теряет сессию; программа не отправляет запрос агенту.
